# start-landing

A clean, single-file landing page starter. No build step, no dependencies — just HTML with inline CSS.

## Getting started

1. Edit `index.html` — copy, colors, links.
2. All theme colors are CSS variables at the top of the `<style>` block.
3. Push to GitHub.

## Deploy with GitHub Pages

1. Go to **Settings → Pages** in this repo.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Pick the `main` branch, `/ (root)` folder, and save.
4. Your site goes live at `https://<your-username>.github.io/start-landing/` in a minute or two.
